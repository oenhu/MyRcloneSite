Privacy Policy

简体中文

1. 适用范围与维护者

本政策适用于由 GitHub 用户 oenhu 维护的 aibcaoo 个人 rclone Google Drive 授权配置，以及本说明网站。aibcaoo 并非 Google 或 rclone 官方产品。本政策描述在你自己的设备运行 rclone、使用个人 OAuth 客户端的方式。

2. 访问的数据与用途

经你在 Google OAuth 页面授权后，rclone 可以访问获准范围内的文件内容和元数据（如名称、文件夹、大小、修改时间和文件标识），用于你发起的列出、上传、下载、备份、同步、创建、移动、重命名和删除操作。完整 Drive 权限可能覆盖整个云端硬盘，不局限于某个文件夹；只读权限不能修改文件。请以实际授权画面和本地 scope 配置为准，并只授予任务需要的权限。Google 提供的访问令牌及刷新令牌用于调用 Drive API 和维持你授权的访问。本网站不要求 Google 登录，不收集 Google 密码。

3. 存储、保留与安全

OAuth 令牌通常保存在运行 rclone 的设备上的配置文件中，直至你删除该配置或令牌失效；下载、缓存、备份和日志可能保留在你配置的设备或目标上，直至你自行清理。开发者不接收或集中保存这些令牌、云盘文件或元数据。请限制配置文件权限，按需启用 rclone 配置加密和设备磁盘加密，保护备份并避免公开日志中的敏感内容。与 Google API 的网络通信使用 HTTPS。

4. 数据传输与共享

Google Drive 数据由你的 rclone 进程与 Google 及你明确选择的存储目标传输。将数据复制到其他云服务或设备是由你指示的操作，并受相应服务政策约束。开发者不出售、出租 Google 用户数据，不将其用于广告、用户画像、信用评估或训练通用人工智能/机器学习模型，也不允许开发者人员读取你的 Drive 数据。

5. Google API 数据有限使用

aibcaoo 对从 Google API 获得的信息的使用及向其他应用传输信息的行为将遵守 Google API Services User Data Policy，包括其中的 Limited Use（有限使用）要求。Google 用户数据仅用于提供本页明确说明、由用户发起的文件管理功能。

6. 撤销授权与删除数据

前往 Google 账号的第三方连接管理，选择 aibcaoo 并移除访问权限，以阻止后续授权访问。在本地使用 rclone 配置工具移除对应 remote，并按需删除配置中的令牌、日志、缓存和下载或备份副本。仅删除本地 remote 不会自动撤销 Google 授权；仅撤销授权也不会删除既有文件副本。Google Drive 上的原始文件由你在 Drive 中另行管理。开发者没有可供代为删除的中央用户文件库。

7. 本网站与第三方服务

本静态网站未加入分析、广告脚本或追踪 Cookie，也没有收集数据的表单。GitHub Pages 作为托管服务可能为提供服务和安全记录访问日志（例如 IP 地址），详见 GitHub 隐私声明。使用 Google 和 rclone 时也请阅读 Google 隐私政策及 rclone 隐私政策。

8. 政策变更与联系

政策更新将在本页发布并更改更新日期。新增数据用途前应更新说明并在需要时重新取得授权。如需询问隐私或数据删除问题，请通过 GitHub Issues 联系维护者。Issues 为公开页面，请勿提交令牌、密码、私人文件或敏感日志。

English

1. Scope and maintainer

This policy covers aibcaoo, a personal rclone Google Drive authorization setup maintained by GitHub user oenhu, and this information website. aibcaoo is independent of Google and the rclone project. This policy describes running rclone on your own device with your personal OAuth client.

2. Data accessed and purposes

After your consent on Google’s OAuth page, rclone can access file contents and metadata within the granted scope, such as names, folders, sizes, modification times and file identifiers. These support listing, uploads, downloads, backups, syncs, creation, moves, renaming and deletion that you initiate. Full Drive access may cover your entire Drive rather than a selected folder; read-only access cannot modify files. Review the actual consent screen and local scope settings and grant only permissions needed for your tasks. Access and refresh tokens issued by Google are used to call the Drive API and maintain authorized access. This website requires no Google login and collects no Google passwords.

3. Storage, retention and security

OAuth tokens are normally stored in the rclone configuration on the device running rclone until removed or invalidated. Downloads, caches, backups and logs may remain on devices or destinations you configure until you delete them. The developer does not receive or centrally store these tokens, Drive files or metadata. Restrict configuration-file access, enable rclone configuration encryption and device disk encryption where appropriate, protect backups and redact sensitive logs. Network communication with Google APIs uses HTTPS.

4. Transfers and sharing

Your rclone process transfers data with Google and storage destinations you explicitly choose. Transfers to another cloud provider or device occur at your direction and are subject to that provider’s policies. The developer does not sell or rent Google user data, use it for advertising, profiling, credit assessment, or training general-purpose AI or machine-learning models, or permit developer personnel to read your Drive data.

5. Google API Limited Use

aibcaoo’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only for the user-initiated file-management features disclosed here.

6. Revocation and deletion

Visit Google Account third-party connections, select aibcaoo and remove access to prevent further authorized access. Remove the relevant remote with rclone’s configuration tool and delete stored tokens, logs, caches and downloaded or backed-up copies as needed. Removing a local remote does not automatically revoke Google authorization; revoking authorization does not remove existing copies. Manage original Drive files separately in Drive. The developer has no central store of user files to delete on your behalf.

7. Website and third parties

This static website adds no analytics, advertising scripts or tracking cookies and has no data-collection forms. GitHub Pages may process access logs, including IP addresses, for hosting and security under the GitHub Privacy Statement. Also review the Google Privacy Policy and rclone Privacy Policy when using those services.

8. Updates and contact

Updates will be published here with a revised date. New data uses require updated disclosures and renewed consent where needed. For privacy or deletion questions, contact the maintainer through GitHub Issues. Issues are public: do not post tokens, passwords, private files or sensitive logs.
